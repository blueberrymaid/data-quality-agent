## 复现方式

```bash
python scripts/01_make_dataset.py   # 生成原始数据与跨表客户档案
python scripts/02_inject.py         # 注入 8 类缺陷并记录真值
python scripts/03_run_agent.py      # 运行智能体（默认 mock；加 --live 走真实 API）
python scripts/04_evaluate.py       # 对照真值评估
python scripts/05_ablation.py       # 消融实验
python scripts/06_make_docs.py      # 生成报告 / PPT / 个人贡献说明
python scripts/07_run_log_digest.py # 生成智能体运行记录
python scripts/08_package.py        # 打包提交压缩包
python scripts/09_make_design_report.py # 生成《项目设计报告》（数据取自 指标汇总.json / 消融实验.json）
python scripts/10_print_run_transcript.py # 回放留档运行到终端（用于附录 B 运行记录截图）
```

本项目的 API Key **不在任何交付物里**：

- 项目内 `.env` 只写 `LLM_API_KEY_FILE=~/.dsh_llm_key`，指向项目之外的独立文件（`%USERPROFILE%\.dsh_llm_key`），
  也可改用环境变量 `LLM_API_KEY` 传入；
- 代码中所有展示配置的位置都经过 `src/config.py` 的 `mask_secret()`，只输出 `sk-5a********b8` 形式；
- 已核验：项目目录、`runs/` 全部事件日志（含全文提示词）、`docs/` 全部文档、提交压缩包内部，
  **均不含密钥明文**；`.env.example` 只留占位说明。

如果你曾把 Key 贴到聊天、截图或公开仓库，建议到服务商控制台吊销并重新生成一个新的，
再把新 Key 写回 `%USERPROFILE%\.dsh_llm_key` 即可继续运行。
